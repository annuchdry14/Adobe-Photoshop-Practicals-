# Practical 04 - Advanced Selection and Colour Correction

## Aim
To learn advanced selection techniques and colour correction using Adobe Photoshop.

## Tools Used
- Quick Selection Tool
- Magic Wand Tool
- Select and Mask
- Adjustment Layers
- Brightness/Contrast
- Color Balance
- Hue/Saturation

## Procedure
1. Open the original image in Adobe Photoshop.
2. Select the required object or area using selection tools.
3. Refine the selection using Select and Mask.
4. Apply colour correction using adjustment layers.
5. Adjust brightness, contrast, and colour balance.
6. Compare the original image with the edited image.
7. Save the project in PSD format and export it as JPG.

## Output
An edited image showing improved selection accuracy and colour correction.

- `Practical_04.jpg`
- Original and edited comparison image

## Result
Successfully performed advanced selection and colour correction in Adobe Photoshop.
