# Practical 03 - Travel Poster Design

## Aim
To create a travel poster using multiple images and Photoshop tools.

## Tools Used
- Move Tool
- Selection Tools
- Layer Mask
- Text Tool
- Layer Styles

## Procedure
1. Open Adobe Photoshop and create a new document.
2. Import three travel-related images.
3. Arrange the images on separate layers.
4. Use layer masks to blend the images.
5. Add a title and supporting text.
6. Apply layer styles to enhance the poster.
7. Save the project in PSD format and export it as JPG.

## Output
A travel poster created using images, layers, masks, and text.

- `Practical_03.psd`
- `Practical_03.jpg`

## Result
Successfully created a travel poster using Adobe Photoshop.
