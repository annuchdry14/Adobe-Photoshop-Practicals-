# Practical 02 - Photo Editing and Retouching

## Aim
To learn basic photo editing and retouching techniques in Adobe Photoshop.

## Tools Used
- Crop Tool
- Spot Healing Brush Tool
- Brightness/Contrast
- Color Balance
- Hue/Saturation

## Procedure
1. Open the original photograph in Photoshop.
2. Crop and straighten the image if required.
3. Adjust brightness and contrast.
4. Correct colours using Color Balance or Hue/Saturation.
5. Remove small spots using the Spot Healing Brush Tool.
6. Compare the original and edited images.
7. Save the project in PSD format and export it as JPG.

## Output
An edited photograph showing improvements in colour, brightness, and image quality.

Successfully performed basic photo editing and retouching in Adobe Photoshop.
